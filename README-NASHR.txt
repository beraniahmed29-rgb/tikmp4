TikMP4 - موقع تحميل فيديوهات تيك توك MP4
=====================================

1) التشغيل محلياً:
- افتح ملف index.html في المتصفح مباشرة، الموقع يعمل بدون سيرفر.

2) النشر (اختر واحدة - مجانية):
- Netlify: اسحب مجلد "Tik Mp4" إلى app.netlify.com/drop
- Vercel: ارفع المجلد عبر vercel.com
- GitHub Pages: ارفع الملفات إلى repo وفعّل Pages
- cPanel: ارفع كل الملفات إلى public_html

3) إضافة إعلانات Adsterra:
- ادخل: https://beta.publishers.adsterra.com/websites
- أضف دومين موقعك وانتظر الموافقة
- أنشئ: Banner 728x90 + Banner 300x250 + Native + Social Bar + Popunder
- افتح ملف ads.js والصق الأكواد في ADSTERRA_CONFIG ثم احفظ وارفع الموقع
- بديل سريع: الصق كود البانر مباشرة داخل index.html مكان <!-- ADSTERRA -->

4) قبل طلب الموافقة في Adsterra:
- انشر الموقع على دومين حقيقي (https)
- غيّر البريد في contact.html لبريدك الحقيقي
- عدّل روابط sitemap.xml لتكون بروابط كاملة https://yourdomain.com/

5) ملاحظات تقنية:
- التحميل يعتمد على API مجاني tikwm.com (بدون مفتاح).
- أعلى جودة: hdplay إن توفرت وإلا play (بدون علامة مائية).
- الموقع static بالكامل، لا يحتاج backend ولا قاعدة بيانات.
